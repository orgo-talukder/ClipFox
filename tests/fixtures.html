Metadata and visible text

Article mentions https://youtu.be/PlainText01. It also references https://www.youtube.com/playlist?list=PLtextplaylist123. The same video appears here again: https://www.youtube.com/watch?v=dQw4w9WgXcQ.

Structured data (JSON-LD) and Open Graph video tags are in the page head.

Malformed links that must be ignored

  • Watch with no video ID
  • Short URL with no video ID
  • Video ID that is too short
  • JavaScript pseudo-link
  • Channel with no ID

Non-YouTube links that must be ignored

  • notyoutube.com
  • youtube.com.evil.example
  • A path that contains youtube.com
  • A userinfo trick
  • Vimeo
  • An unrelated redirect
